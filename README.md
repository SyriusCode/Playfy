# Playfy

Estructura inicial de una tienda online de videojuegos.

## Estructura

- `index.html`: página de inicio.
- `pages/`: páginas del sitio.
- `assets/css/`: estilos generales, compartidos y específicos por página.
- `assets/js/`: scripts comunes y específicos por página.
- `assets/img/`: recursos gráficos organizados por tipo.
- `assets/fonts/`: fuentes del proyecto.
